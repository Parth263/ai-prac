### Answer 1: Theory and Concepts Related to Kruskal’s Algorithm

**1. What is Kruskal’s Algorithm?**
- Kruskal’s algorithm is a greedy algorithm that finds the **Minimum Spanning Tree (MST)** of a connected, undirected, weighted graph.
- The MST connects all vertices with the minimum total edge weight without forming cycles.
- Used in network design (e.g., minimizing wiring in electrical grids).

**2. Key Components**
- **Graph**: An undirected graph with nodes and weighted edges.
- **Edges**: Sorted by weight to select the smallest ones first.
- **MST**: A tree spanning all vertices with the least total edge weight.
- **Union-Find**: Data structure to detect cycles and manage connected components.

**3. How Kruskal’s Works**
- Sort all edges by weight (ascending).
- Iterate through sorted edges, adding each to the MST if it doesn’t create a cycle.
- Use Union-Find to check if adding an edge connects two nodes already in the same component (which would form a cycle).
- Stop when the MST includes all vertices (V-1 edges for V vertices).

**4. Data Structures**
- **Adjacency List or Edge List**: Represents the graph as a list of edges (u, v, weight).
- **Union-Find**: Tracks connected components with `find` (gets root of a node) and `union` (merges components).
- **Sorted Edges**: Edges sorted by weight for greedy selection.

**5. Time and Space Complexity**
- **Time Complexity**: O(E log E) for sorting edges + O(E log V) for Union-Find operations, where E is the number of edges and V is the number of vertices. Typically simplified to O(E log V) since E ≤ V².
- **Space Complexity**: O(V + E) for the Union-Find structure and edge list.

**6. Properties**
- **Greedy**: Always picks the smallest-weight edge that doesn’t form a cycle.
- **Complete**: Finds an MST if the graph is connected.
- **Optimal**: Guarantees the minimum total weight for the spanning tree.

**7. Applications**
- Network optimization (e.g., telecom or internet cabling).
- Clustering (e.g., grouping similar data points).
- Approximation algorithms for problems like Steiner Tree.

**8. Example Context**
- Given a graph with nodes 'A' to 'F' and edges (e.g., A-B: 4, B-C: 1), Kruskal’s sorts edges by weight and builds the MST by adding edges like B-C, B-D, D-E, avoiding cycles.
