#### Key Programming Concepts Used
1. **Loops**:
   - A **loop** repeatedly executes a block of code until a condition is met.
   - In this code, a `while True` loop keeps the chatbot running, displaying the menu and processing user inputs until the user chooses to exit.
   - Purpose: Ensures continuous interaction, allowing users to perform multiple actions without restarting the program.

2. **Conditional Statements (`if-elif-else`)**:
   - Conditionals execute different code blocks based on conditions.
   - Used to map user input (e.g., '1' to '7') to specific actions (e.g., track order, exit).
   - Purpose: Directs the program flow based on user choices, handling valid and invalid inputs.

3. **Input/Output**:
   - **Input**: The `input()` function captures user text (e.g., choice, order ID).
   - **Output**: The `print()` function displays menus, responses, and errors.
   - Purpose: Facilitates user interaction by reading inputs and showing results.

4. **Lists**:
   - A list (`feedback_log`) stores user feedback as strings.
   - Purpose: Maintains a record of feedback to display when the user exits, adding a simple memory feature.

5. **String Manipulation**:
   - Methods like `strip()` remove leading/trailing whitespace from inputs.
   - String formatting (e.g., f-strings) creates dynamic responses (e.g., `f"Order {order_id} is..."`).
   - Purpose: Ensures clean input processing and user-friendly outputs.

6. **Functions**:
   - A function (`display_menu`) encapsulates the menu display logic for reusability.
   - Purpose: Organizes code, reducing repetition and improving readability.

7. **Break Statement**:
   - The `break` statement exits a loop (e.g., when the user selects '7').
   - Purpose: Terminates the chatbot when the user chooses to exit.
